Sheltered 2 - Infinite Generator Fuel v0.1.0 (BepInEx 5 BUILD KIT)

REQUIREMENTS
 - Steam Sheltered 2 on Windows
 - BepInEx 5 for Unity Mono 64-bit (same install as your other working mods)
 - Windows .NET Framework csc.exe and netstandard.dll (the installer searches both)

WHAT IT DOES
 - Fuel in an already fueled generator does not fall from routine electricity production.
 - Generator max electrical output per IN-GAME HOUR defaults to 200 (usually 8 in vanilla).
 - Does not make an empty generator auto-start; add a fuel can once if fuel is 0.
 - Allows adding more fuel as normal.
 - Does not alter batteries, incinerators, the warehouse petrol supply, or tutorial ForceFuelDepletion.
 - Uses only the generator power source / storage calculation methods.
 - Does NOT change the existing Infinite Durability mod or the other working mods.

INSTALL
 1. Close Sheltered 2 and back up your current save.
 2. Extract ZIP; open the Sheltered2_InfiniteGeneratorFuel_v0.1_BuildKit folder.
 3. Double-click BuildAndInstall.bat.
 4. When prompted, enter YOUR GAME FOLDER, for example:
      E:\SteamLibrary\steamapps\common\Sheltered 2
 5. Successful build installs to:
      Sheltered 2\BepInEx\plugins\InfiniteGeneratorFuel\Sheltered2.InfiniteGeneratorFuel.dll
 6. Start game and examine generator power and fuel over several hours/days.
 7. If the generator has 0 fuel, add at least one petrol can before testing.

CONFIG OPTIONS (generated by BepInEx after first successful launch)
  BepInEx\config\suthipot.sheltered2.infinitegeneratorfuel.cfg
  [Generator]
  InfiniteFuel = true
  OutputPerGameHour = 200

  Both options are independent: you may keep 200 output without infinite fuel,
  or freeze fuel while retaining the original 8 output. Exit game before editing;
  the settings are read at startup and require game restart.

TEST CHECKLIST
 [ ] After entering a save, generator's max output shows around 200 per game-hour.
 [ ] Generator with positive fuel generates electricity as before.
 [ ] Fuel level stays unchanged while operating, including under heavy demand.
 [ ] Refilling fuel still works.
 [ ] Other power sources (batteries etc.) retain normal behavior.
 [ ] New-game tutorial (if used) still progresses when scripted depletion occurs.

TROUBLESHOOTING
 - Compile error: copy full console output to ChatGPT.
 - In-game patch error: attach BepInEx\LogOutput.log.
 - Check for log line: "Infinite Generator Fuel v0.1 active".
 - This is an EXPERIMENTAL BUILD KIT: it contains C# source + Windows installer,
   NOT a precompiled DLL. Linux environment could not compile against your
   local BepInEx dependencies or test in Sheltered 2.

IMPLEMENTATION NOTES
 - Hooks Object_PowerSource.Start to set m_maxOutputPerGameHour on generators,
   before base Start computes the m_outputPerSecond from it.
 - Temporarily raises the reported fuel reserve within OnNewTick, GetPower_Tick,
   and RequestPower for generators with positive fuel. Restores actual reserve
   at exit from each game method, preserving its original value for saving.
 - Other power sources and an empty generator use vanilla behavior.
